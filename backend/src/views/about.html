System Design & Specifications

About the Project

Engineered as an independent, clean-room implementation of the Alumni Tracking System coursework, emphasizing enterprise architectural patterns, containerization, and zero-touch deployment.

🎯 Architectural Philosophy

This implementation avoids monolithic, single-file scripts in favor of a clean layered structure. Each layer has a single responsibility: routing delegates to controllers, controllers orchestrate input/output, and services execute domain business logic and numeric validation.

📋 Technology Stack & Environment

Component Technology Version / Details
Runtime Node.js v20+ LTS (Alpine Linux in Docker)
HTTP Framework Express v4.19+ with Helmet security headers & Morgan logging
Database PostgreSQL 16-Alpine with isolated persistent volume
Containerization Docker & Compose Multi-container orchestration with dependency health checks
Deployment Rule One-Command Rule docker compose up --build
